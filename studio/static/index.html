    地图简报

    已打开某张地图时，「写出提示词」会改这一张，不会另开条目。要全新地点请先点「新建地图」。可站立的平地和高台必须画在同一侧视图层（台阶断面），不要 3/4 透视把高台画到背景里。

    Lyria 3 Clip · 30 秒纯器乐循环，偏格斗压迫感（少欢快旋律）。读取 visual 与可选地图图，入库后写入 stage.json 的 bgm，对战端自动循环。

    删除会清掉工坊设定、草稿，以及已入库的 assets/game/stages/。试玩端下一场对战不再出现这张图。

    立绘简报

    独立于对战英雄：只出青屏动作条 → 切分 → 去青导出透明 PNG到本机，不写 fighter、不进 game/heroes。

    勾选要出的动作；改帧数（三视图固定 4）。也可添加自定义类别。推理只按清单写提示词，不会自创槽位。

    卡片里的提示词可直接改，会自动保存；也可点「微调提示词」写不满意的点让系统重写，再点「生成草稿 / 再出一版」。动作条必须跟三视图同一人；人物主体禁止青/青绿/水色（便于去青抠图）。草稿可「丢弃」后重出。身长校对保存本套时会写回草稿并自动去青导出该槽透明帧。「删除这份立绘」会清掉设定、草稿与已导出透明帧。

    导出目录：当前工程 assets/studio/exports/portraits/<id>/

    英雄简报

    画得不像时，上传正面/半身真人照片。生成「人物三视图」会按脸与体态对齐成像素角色；服装仍听形象文字。之后动作条自动跟三视图，不必每槽再贴照片。

    只填这三项。系统会推理关键帧提示词（动作 + 弹道 fx_*）和 moves 数值。先单独生成并采用入库三视图，再一键生成其余套图（同时 3 张）。出图后先切分播放确认，再入库；切分不会写入游戏。原图会留着，可换一种切法而不重新生图。出图在后台跑，等待时可切换去做另一个英雄或地图。

    风格锚点必须先入库。三视图确定后才能批量出动作条。单槽不满意可「重写提示词」或「再出一版草稿」。切分只预览；「重新去青覆盖」只对已入库图再抠青边。「一键统一人物尺寸」按 idle 躯干身高对齐（不含出场/战败/战胜 CG）。「身长校对工作区」含出场/战败/战胜，可逐套微调后直接入库。删除草稿只清工坊设定和草稿，已入库的游戏资源会留着。

    台词与配音

    默认走 Gemini-TTS。游戏只播六句：选人浏览、出场、受击（短促）、奥义、胜利、战败。普攻与技能不配音。开播后会完整念完。点「生成并入库」才写入 assets/game/。

    上方可搜中文名、英文名或代码。高棉语 km-KH 目前 Google 不支持合成，请用录音克隆，或试 th-TH / vi-VN。
